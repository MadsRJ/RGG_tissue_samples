# RGG_tissue_samples
Shiny-app development of tissue sample overview. Work in progress.

# In R, run:
```
source("https://raw.githubusercontent.com/MadsRJ/RGG_tissue_samples/main/scripts/ShinyApp.R")
```

You can now select "Open in browser", and start filtering according to your desired metadata filters. You can also export sample tables as CSV or Excel files.
